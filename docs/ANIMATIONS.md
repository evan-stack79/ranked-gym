## Harmonisation (fichiers _rouge = œuvres dérivées, même licence)
- Couleurs chaudes saturées → famille rouge #ff0702 à clarté égale ; couleurs froides ou peu saturées → gris chauds ; peau conservée (états 1, 2, 3, 5, 6, 8, 10).
- Calques retirés : cercle bleu de fond (état 6, « Layer 2 »). Fond transparent partout.
- Audit automatique : 0 jaune criard, 0 violet, aucune image bitmap embarquée.
- Script : `src/hy/harmonize.py`, réglages par état : `src/hy/final.json`.
