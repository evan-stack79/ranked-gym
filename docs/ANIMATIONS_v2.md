## Harmonisation (fichiers *_rouge.json = œuvres dérivées, même licence)
- Couleurs chaudes saturées → famille rouge #ff0702 à luminosité égale ; couleurs froides/désaturées → gris chauds ; blancs conservés. Peau humaine conservée (état 11).
- Audit : 0 jaune criard, 0 violet, aucun calque de fond plein (fond transparent), aucune image bitmap embarquée.
- Thèmes : 1 seul soleil (état 2), 0 lune, pas de batterie ; aucun doublon avec its-sleeptime, alarm ni les 8 Lotties de la page Sommeil.
- Script : src/mc2/harmonize.py (réglages par état dans src/mc2/final.json).
