Session restore path
1. Boot splash / AppColdLaunch (silent brand, no “Chargement” / “Récupération des données”)
2. AuthProvider restores session:
   - Convex: token + getSession. Valid user → cache + hydrate, never mount WelcomeScreen
   - Expired (remote null, no network error) → clear token/cache → WelcomeScreen
   - Network/service error + local token → keep local session (cache or placeholder), skip welcome
   - No token → WelcomeScreen
   - Supabase: getSession() local persist (already offline-capable)
3. isLoading → AppBootScreen silent. !isAuthenticated → WelcomeScreen. isAuthenticated → app/onboarding
