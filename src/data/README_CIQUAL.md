# Table Ciqual 2020 (ANSES)

- Fichier embarqué : `ciqualKcal2020.json` — uniquement la colonne
  **Energie, Règlement UE N° 1169/2011 (kcal/100 g)** (`const_code` 328).
- Aliments sans kcal (teneur `-`, traces, `< x`) **exclus** (jamais affichés à 0).
- Source d’extraction : copie archivée (web.archive.org) du XML officiel
  du 07/07/2020, car ciqual.anses.fr était en maintenance le 22/10/2026.

**Avant toute mise en ligne** : retélécharger le fichier depuis le site
officiel ANSES / data.gouv.fr et régénérer ce JSON s’il existe une table
plus récente.
